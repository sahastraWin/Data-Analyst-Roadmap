## 🎯 Interview Prep — Platform Guide

<div align="center">
<img src="https://user-images.githubusercontent.com/74038190/212284087-bbe7e430-757e-4901-90bf-4cd2ce3e1852.gif" width="500" />
</div>

| Platform | Best For |
|----------|----------|
| 🥇 **StrataScratch** | Real SQL questions from Meta, Google, Airbnb |
| 🥈 **DataLemur** | Company-specific SQL with great explanations |
| 🏅 **LeetCode (Database)** | FAANG-level SQL problems |
| 📊 **Kaggle Notebooks** | Real-world EDA and Python techniques |
| 🎓 **HackerRank** | SQL + Python certificates for LinkedIn |
| 💼 **Exponent** | Business case studies + mock interviews |

> **4-Week Interview Sprint:**
> Weeks 1–2: SQL (1 problem/day on StrataScratch + DataLemur)
> Week 3: Python EDA (Kaggle notebooks)
> Week 4: Stats review (StatQuest) + Behavioral (STAR method)
